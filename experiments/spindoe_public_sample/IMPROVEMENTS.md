# SpinDOE 匹配与旋转回归改进

本次改进保持官方图像、网络热图和检测阈值一致，不修改 upstream 文件，也没有训练商标检测器。

## 已实现

1. `point_matcher.py`：按观测坐标建立确定顺序，尝试所有非退化的基准点对，使用一一对应的特征分配验证候选姿态。避免原实现只依赖输入列表的前两个点。同一参考点不能重复解释多个观测点。报告不同姿态竞争解的匹配分数，但不将它称为置信概率。
2. `corrected_spin.py`：保留只修正上游符号的适配器作对照，新增 `BoundedSpinRegressor`。沿用四元数平面 RANSAC 选轴与内点，使用圆周相位拟合替代启发式 unwrap。相位由四元数投影的平方得到，因此不受 q 与 -q 表示同一旋转的影响。搜索上下限必须显式提供。
3. `run_improved.py`：复用已保存的官方网络热图，对比默认算法、上轮大小排序诊断和本次匹配。生成逐帧数据、指标与60倍慢放。

几何匹配函数接收 `(N,3)` 的球面特征位置，不依赖特征本身是圆形。但它仍需要已知参考点阵；本次输入仍来自官方圆点检测网络。换成商标，需要新的特征检测/跟踪以及参考对应，不能仅更换输入视频。

## 当前样本结果

| 版本 | 通过单帧姿态阈值 | 角速度结果 |
|---|---:|---|
| 官方默认点顺序 | 7/22 | 无整段估计 |
| 上轮按检测斑块大小排序 | 12/22 | 132.9119 rps 候选 |
| 本次多基点 + 有界圆周相位拟合 | 12/22 | 132.8370 rps 候选，10帧参与回归 |

本次候选对参与回归的姿态，其前向姿态残差中位数为6.23°，对全部12个已接受姿态为7.40°。这些是内部一致性指标，不是实际旋转轴误差。与上轮最好的大小排序诊断相比，覆盖率没有进一步提高；改进主要在点顺序与数值扰动下的稳定性。

本次搜索范围为±190.618 rps，按原采样中位间隔的一半倒数选取。它只是此次搜索假设，不能排除范围外转速的混叠，也不是相机的物理测量上限。最优与次优候选信息记录在 `outputs/improved/results.json` 的 `phase_fit`，coherence 是相位一致性分数而非正确概率。

发现的另一个上游问题：几乎相同的姿态（约1e-14°差异）可能使原启发式 unwrap 从约132.9 rps跳到约88.7 rps。新相位拟合在两组姿态上给出的转速相差约8e-10 rps；有跳帧的133 rps已知旋转测试也通过。

## 运行和验证

在本目录运行：

```sh
.venv/bin/python run_improved.py
.venv/bin/python -m unittest test_point_matcher test_corrected_spin -v
```

`run_improved.py` 依赖上轮 `run_sample.py` 已生成的 `outputs/baseline_estimates.npz`。11项测试通过，覆盖已知姿态、点顺序变化、无效输入、旋转轴与正反方向、跳帧、四元数符号变化、微小扰动和时间原点变化。

输出视频：`outputs/improved/improved_60x.mp4`。左侧原图，中间单帧匹配，右侧整段旋转预测。

## 当前限制

- 一个短片段且没有独立旋转真值，不能据此判断真实精度或对其它球的泛化。
- 前端仍是点阵专用网络；尚未实现商标特征检测，也未测试 G1 事件数据。
- 多基点仍可能遇到错误对应或多解；球面坐标依赖现有裁剪、球心与半径假设。
- 当前四元数平面后端对严格恒定姿态会退化并返回无效；无旋/极低旋转的专门判定尚未实现，不能把无效输出当无旋。
- 多基点匹配当前样本22帧约7秒，适合离线分析，尚未优化实时性能。

商标路线下一步应保留球面运动模型，用商标笔画转角/交点等可重复定位特征建立轨迹；仅使用商标中心会损失方向约束。在有真实商标序列前，不将合成或点阵结果当作商标识别能力。
