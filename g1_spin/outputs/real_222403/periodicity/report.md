# 17.58 秒真实录像：独立周期性检查

输入：`DSP03F100025_20261029_222403.raw` 的官方 SDK 解码事件；以下时间均相对首事件 `197754251 us`。这是非标定的周期性证据，不是真值，也不输出三维旋转轴。

## 方法

- 固定矩形球区 x=[500,620)、y=[160,250)，包含上半球标记及部分边缘；没有根据期望转速筛选数据。
- 2 ms 事件计数；12×9 空间格、ON/OFF 分开作为216维图案特征，每时刻归一化总事件数。
- 每2秒做去均值空间特征自相关，与事件率周期互相核对。
- 同面积左侧背景区 x=[350,470)、y=[160,250) 作为对照。
- 减速曲线用事件率50 ms Gaussian平滑后找突出峰，最低突出度16000 events/s，峰间至少180ms；相邻峰间隔的倒数只代表重复频率。所有阈值都是工程选择。

## 结果

空间图案重复的主要滞后随时间增加，事件率大峰间隔也连续增加。假设一次图案/事件率重复对应一圈，条件性转速候选为：

`cycle_candidates.csv` 保存全部29个区间的峰时刻、间隔、频率和RPM候选；没有单调拟合或强制减速约束。少数相邻候选略有上升，反映峰形变化与噪声。

0–4s球区主要频率3.25Hz，其功率8073，而同面积背景在同频率功率约0.00884；4–8s、8–12s也相差多个数量级。因此低频重复不是仅凭全图共有频闪得出的假象；这不排除其它光照影响。

`repeated_patterns.png`显示早期和后期的峰时刻/半周期/下一峰三个20ms事件图：两次峰的图案近似重复，而半周期形态明显不同，提供一圈假设的支持，但不能严格排除相似标记导致的整倍数歧义。

## 建议分析片段

- **1–3 s**：转动明显、周期较短、事件充足，适合快速段。
- **6–8 s**：减速中段，空间重复和事件率周期清楚。
- **10–12 s**：较慢段，仍有清楚标记运动，可检验更长时间窗。

**14.5s之后不建议报告稳定周期RPM**：在短观测段内已缺少足够重复，16.5s后球区事件接近背景。此时应报告不足以估计，不能直接据此填0RPM。

## 不能直接采用的结果

空间局部特征的频谱最强峰经常在约3–6倍于完整重复频率处（例如早期16Hz），这与多标记/局部图案通过有关。不能把最强FFT峰直接乘60认作真实球RPM。

这个分析不证明固定球心假设，不估计旋转轴，不校准球半径。应与几何测量和s-CMax方向/速度交叉检查；不能把这里的候选当作独立转速标签反填。
