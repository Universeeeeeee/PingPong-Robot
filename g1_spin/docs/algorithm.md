# 固定球心旋转估计：算法与验证边界

## 范围与当前实现

仅处理固定相机、固定球心的离线事件；不包含飞行球跟踪、神经网络、ROS 或控制。RAW 通过 Ubuntu 已有 `~/g1_spin/scripts/event_io.py` 的官方 DVSense 1.3.0 读取接口接入，不自行解码 EVT3.0。已对一份官方 RAW 完成 inspect：840449 个事件、1280×720、事件时间跨度 3.038474 秒，无时间戳倒序；已导出 100 ms 片段预览，原文件 SHA256 前后不变。这验证了该文件读取与预览链路，不代表测得真实乒乓球转速或物理精度。

内部事件为 `x, y, t_us, polarity`。时间戳保留整数微秒；先做整数相减，再乘 `1e-6` 转为相对秒。重复时间戳允许存在，不能当作丢包；倒序、跳变、坐标越界需单独报告。人工指定球心和半径，内部圆裁剪降低轮廓误差；球内事件仍可能来自背景透射、频闪或噪声，不能全部称为商标事件。

## 几何与 s-CMax

坐标系为 x 向图像右、y 向图像下、z 远离相机；球心为原点，球半径归一化为 1。可见半球 z 为负。角速度遵循右手定则，正 z 旋转在图像中表现为顺时针。

对 ROI 内事件提升：

```
x = (u - cx) / r
y = (v - cy) / r
z = -sqrt(1 - x*x - y*y)
```

禁止将球外点强行压回球面；仅允许浮点舍入量级的根号截断。当前参考时间取窗口中点，补偿为 `R(-omega * dt_seconds) @ point`，采用 Rodrigues 公式。补偿后的点允许位于任意半球，不再次按可见性丢弃，保证各候选使用相同事件。

用 `theta=asin(z)`、`phi=atan2(y,x)` 构造球面 IWE。每事件以双线性权重累积总质量 1，phi 周期连接；纬度边界采用反射平滑。当前网格 64×128，使用 5×5、sigma=1 的 Gaussian。最大化 `Var(IWE / N)`；对于固定事件数 N，该归一化不改变最优解。这里累积非负计数，不按 ON/OFF 正负抵消。

当前初始化为确定性的多轴、多转速粗搜索，再对多个分离初值进行 SciPy Nelder–Mead 优化。转速上限可配置。输出大小 `norm(omega)`，rps 为大小除以 `2*pi`，rpm 为 rps 乘 60；仅在有效且非零时计算归一化轴。

## 与论文的对应和差异

主要来源：[Sony v2 §3.3、§4.2](https://arxiv.org/html/2606.26780v2)，以及 [Gossard 2024 §3.3、§4.5](https://arxiv.org/html/2404.09870v1)。

Sony 明确描述负 z 正交球面提升、逆向 SO(3) 补偿、球面角坐标 IWE、方差最大化、双线性累积、5×5 sigma=1 平滑，以及大小搜索后 Nelder–Mead。上述核心数学与之对应。其初始化使用事件局部平面拟合光流，提升切向速度 v，并以 `P=v*v.T/(v.T*v)` 投影观测，再堆叠 `P*(-[x]cross)*omega=P*v` 求最小二乘。

**当前已实现独立光流 Baseline 和 benchmark 三方法对照，但光流尚未接入 s-CMax 初始化。** 多轴粗搜索是工程替代，不能称作完整复现 Sony 原流程。网格大小、方向数、大小采样、优化容差、事件下采样、ROI 内缩比例及质量阈值也是工程选择。本文获取的 Sony HTML 未包含其引用的补充材料，不能推断其未公开参数。论文的 0.1 方差阈值不能直接用于本实现的归一化 IWE。

Gossard 的事件率周期方法依赖商标出现/消失。当前周期 Baseline 仅提供候选频率和条件性转速，不能估计三维轴；多标记可产生倍频，频闪也能形成周期。单点完整速度满足 `x cross v = omega - x*(x dot omega)`，也不足以独立恢复三维轴。当前 `optical_flow.py` 使用局部时间平面的标量法向约束处理 aperture problem，并检查秩、条件数与残差，未把法向流当完整速度。

## 有效性与合成测试限制

当前质量检查包括事件不足、时间跨度不足、无明显旋转证据、优化不收敛、接近搜索上界、多初值接近同分但结果不一致、空间特征退化，以及分析阶段相邻时间窗严重不一致。失败返回 `valid=false`，角速度、轴和转速为空；被拒绝候选仅作为诊断保留。质量检查是启发式，不是统计置信度；优化收敛和对比度提高不证明物理正确。

合成器生成独立旋转球面点的可见轨迹，使用亚像素坐标和人为极性，仅将事件字段送入估计器，不传递点身份或真值。它是**几何调试数据，不是光照—纹理—对数亮度阈值驱动的 DVS 模拟器**。因此合成成功不能验证像素量化、商标边缘法向流、传感器响应延迟、事件丢失或真实噪声。

待补充：有独立真值的真实旋转数据；物理事件或真实商标模拟；将可靠光流用于 s-CMax 初始化；有限商标可见性负例；更可靠的背景干扰和局部可观测性检查；可配置质量阈值。当前已有独立周期/光流/s-CMax 对照入口，相邻窗口一致性门槛已接入，但仍是工程质量判据。经纬度网格不是等面积参数化，极点附近存在畸变，需不同轴方向对照。轴误差应使用有向夹角 `acos(dot(axis_est, axis_gt))`，不能取点积绝对值掩盖反向错误。<5% RPM、<5°轴误差只能作为理想合成调试目标。

## 三种文献方法的实质区别

| 方法 | 运动约束/目标 | 当前项目关系 |
| --- | --- | --- |
| Gossard 2024 §3.3 | 局部光流补切向 z，再计算单点叉积并平均；事件率周期辅助选择流窗口 | 周期思路参考，未实现其完整光流方法 |
| Nakabayashi 2024 §4 | 式(9)负深度提升；式(10)/(11)四元数按 `omega*(t_ref-t)` 补偿；丢弃 z 投回平面；§3.2 式(3)带极性 IWE，最大化方差 | 不纳入平移估计、不采用平面 IWE；仅交叉核验几何 |
| Sony §3.3 | 投影光流约束最小二乘初始化，球面角坐标无符号 IWE，大小搜索后 Nelder–Mead | 球面核心已实现；光流初始化以工程粗搜索替代 |

Nakabayashi §5.1 使用 50000 事件、Adam 1500 次迭代；§5.2 用 Blender 渲染加 ESIM（正负阈值 0.15）产生合成数据。这些参数不是本项目默认值。其 §6 明确真实实验缺少真值，仅作定性验证；不得把其合成 500 rps 结果转化为 G1 的真实保证。Sony 指出的平面投影前后半球混淆和边缘聚集，正是本项目采用球面 IWE 的依据。

## 当前独立光流 Baseline 的推导

在同极性局部事件上拟合 `t_seconds = a*u_pixels + b*v_pixels + c`。沿运动轨迹求导得到 `a*du/dt+b*dv/dt=1`；由 `dpoint/dt=omega cross point` 和像素半径 r，得到：

```
r * cross(point, [a,b,0]) dot omega = 1
```

堆叠这些标量约束做最小二乘。这是依据刚体运动关系推导的工程方案，不是 Sony 文中 lifted-P 公式的逐字实现。局部邻域为 4 px、±2 ms，同极性至少 10 点，最多采样 300 个中心；必须具有二维空间支撑和稳定平面残差。求解至少 12 条约束、rank=3、condition≤100、约束 RMS≤0.35，均为当前工程选择。

benchmark 将此方法作为独立对照；当前 s-CMax 仍使用多轴粗搜索初值。理想点轨迹生成器不具有真实运动边缘的局部二维事件面，光流返回样本不足或退化是允许且必须如实报告的结果，不能为提高对照有效率而绕过质量门槛。
