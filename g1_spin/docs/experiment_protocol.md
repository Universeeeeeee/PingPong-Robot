# DVSLume-G1 固定球旋转录制协议

## 准备

1. 固定 G1 和球旋转装置，确保球心在各时间窗内不移动，避免支架振动。使用原有官方 PoE 设备；不修改网络、SSH、固件或无关工程。
2. 优先使用带独立编码器或经校验转速计的装置。参考转速由该仪器记录；参考轴需经相机坐标系标定。未测量的标签留空，禁止用估计结果填写真值。
3. 使用明显且非对称的商标或人工标记。调整工作距离与焦距，使球面纹理占有足够像素且清晰；记录球半径。固定旋转时外轮廓可能没有事件，不依赖自动霍夫圆。
4. 使用稳定、充足照明，先录制空场检查频闪。尽量移除运动背景。用 Insight 检查商标运动是否产生可辨事件；记录 Bias，勿直接照搬 Prophesee 论文参数。
5. 核对 Insight、SDK、相机型号和固件版本，记录本次实际值。确认 RAW 输出目录可写、磁盘充足；使用新实验目录，不覆盖已有原始数据。

## 采集矩阵

每个条件至少独立重复三次，保留完整原始 RAW：

| 条件 | 目的 |
| --- | --- |
| 静止带标记球、空背景 | 无旋转和噪声负对照 |
| 已知低、中、高转速 | 检查范围与误差，可从 500/1000/2000/3000 rpm 中按装置能力选择 |
| 正转和反转 | 验证方向符号 |
| 不同三维旋转轴 | 验证轴恢复与退化情况 |
| 不同商标朝向、无明显标记球 | 测试可见性和应当失败的条件 |

启停期间另行标记；稳定段建议至少 1 秒，并包含多个完整周期。检查周期 Baseline 时尤其不能只截取 10 ms：500 rpm 一圈约 120 ms。三维分析先用 10 ms，再对照 5/20 ms 和配置的步长，保留所有失败窗，不只报告好看的片段。

## 每次记录表

- 实验编号、重复编号、采集日期时间和时区。
- 相机型号、序列号（如可得）、固件、Insight 与 SDK 版本。
- 镜头、焦距/焦点、工作距离、分辨率。
- 球心 cx/cy、半径 r、ROI 内缩比例及确认 ROI 的预览图。
- 照明种类和亮度（如可测）、Bias、背景情况。
- 球面标记、旋转方向、稳定段时间范围。
- 参考 RPM、测量仪器和精度；参考轴、标定方式及坐标系，缺失则留空。
- RAW 绝对路径、文件大小、SHA256；配置文件路径与分析版本。

RAW 录制关闭后计算 `sha256sum /实际路径/recording.raw`，保存输出；分析仅只读打开原始文件。

## 录制后验收

1. 先运行 `inspect`，核对分辨率、时长、事件率、ON/OFF 比例、时间戳顺序和异常；解码失败先检查本机官方 SDK 实际 API，不自行猜测 EVT3.0 编码。
2. 运行 `preview`，导出 1/2/5/10 ms 累积图及视频。SSH 无 GUI 时保存预览后人工填写 cx、cy、r；确认有效事件确实来自球面标记，球外背景明显时先改善采集。
3. 保存 ROI 和完整配置，再运行 `analyze`。核对 JSON/CSV 的失败原因、有效窗口比例、RPM 分布、轴分布和补偿图；收敛但轴混乱仍应判为未通过。
4. 有独立真值时计算转速绝对/相对误差和有向轴角误差；报告全部条件及失败比例。无标签只报告估计和质量，不宣称精度达标。

已通过一份官方 RAW 的读取检查（840449 事件、1280×720、3.038474 秒，无时间戳倒序）和 100 ms 片段预览，原 RAW hash 不变；这只验证数据链路。当前尚未测得有独立真值的真实乒乓球旋转。下一步人工操作是固定装置、确认独立转速参考、设置稳定照明、用 Insight 录制并提供旋转 RAW 路径和 ROI，再验证真实估计性能。
