原始RAW文件第一次被监测到时，其主机monotonic时间为1222767189563373ns；匹配最近D455接收帧并查回原始库，得到粗起点205.443818693s。因此当前复核使用：

```
D455数据库相对时间 ≈ 事件首个CD之后的秒数 + 205.443818693
```

该值只是用于并排观察的粗偏移，不能把小数位数当精度。文件写入/监测延迟未标定，也没有同硬件触发或可确认的独立脉冲对。未估计时钟漂移，没有给出可认证的同步残差；不能直接将这个映射用于20ms窗口的定量球心补偿。

## 主要成像问题

1. **D455主动红外点阵进入事件相机。**球、衣物和手臂上均有明显点阵事件。此前为补救D455短曝光过暗而开启投射器，是本次采集配置的不足；其对事件相机的影响在正式录制前没有完成双路联合验收。点阵固定于照明投影，不能当作附着在球面并随球旋转的标记。静止/近静止背景也生成大量事件，与高事件率一致；但没有关闭投射器的同场A/B，不能给出干扰事件的精确占比或认定全部异常均由投射器导致。
2. **D455中球像约数十像素直径**，代表画面约25–35px，属于视觉估计而非标定测量。对亚像素球心精度要求高；缩放显示不能增加测量信息。轮廓由点阵照亮，不是理想均匀外轮廓。
3. **8.5ms曝光**在90FPS帧周期约11.1ms下占比较高，移动/摇晃期间可能拖影。没有同步高精度中心真值，不能认证本轮补偿精度。
4. 两相机没有提供外参、运动平面或深度投影验收。时间对齐即使改善，也不能直接把IR球心像素转为事件球心像素。

## 可以使用和暂不使用

可用：检查SDK录制、文件关联、RAW解码、DB回放、曝光元数据、帧号缺口、动作顺序与粗时间对应；可作投射器干扰和高负载失败分析材料。

暂不用于：严格RPM/三维轴误差、20ms精确球心补偿A/B、将点阵对比度峰当自转真值。故本轮没有输出虚假的精确转速或宣称同步完成。

## 建议的下一次最短验证

- 先只开两路预览，关闭D455投射器，验证事件背景是否干净；D455f若无投射器看不清，使用稳定且与相机波段匹配的均匀照明/另一台参考相机。不要靠投射点阵照亮球来建立事件旋转参考。
- 适当缩短工作距离，增加参考球像尺寸；重新核验两路共同视野，先观察10秒静止球、10秒纯平移，再录正反转。
- 在能看清轮廓的条件下逐步缩短曝光，500μs是目标试点，不能忽略亮度。记录实际曝光及帧间隔，不只读取设置值。
- 同步标记采用独立、可识别的不等间隔脉冲/动作，首中尾均记录；若要求1ms同步，应核对硬件触发或采用可量化的光学编码，90FPS普通帧级动作本身不保证1ms。
- 记录带宽验证可先减少不必要的深度/第二IR流，观察原始文件帧号缺失是否下降，再决定正式采集配置。
