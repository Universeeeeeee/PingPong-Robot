# B1：布局无模板局部关联压力测试（运行前冻结）

没有人工确认哪个特征是商标/Logo，F仅为临时局部特征名。没有真实换布局数据。B0本来就不使用三维布局，不把本轮包装成新增加的布局自由算法。

- 复用同SDK原始事件、三段100ms、5ms非重叠20帧、9个已人工审阅种子。正常匹配仅从frame10的人工锚点向未来frame19，共10帧含seed；不从未来反向传播产生观测。相邻帧的FB检查只读取来源/当前帧，不用未来块。原始前10帧仅作背景证据。
- 匹配与拒绝完全保留B0：27×27双极性distinct-pixel occupancy、sigma0.8/默认truncate4、±12px整数平移、≥12不同像素、score≥0.35、排除最佳Chebyshev半径3px后次峰差≥0.025、FB≤2px、不触搜索边。逐帧模板更新，拒绝后停止、不自动复活、不在新位置复用同一F。固定参考模板/亚像素等算法改进本轮不做。
- 基线：9条×10帧逐字段复现B0 forward结果；再逐F独立调用同函数验证等价。B0各F原本就独立，删除seed列表不等于删除邻居事件，更不算换布局。
- 干预代表预先固定为early_turn/middle/late的F1，不按B1结果替换。所有干预frame13–15（名义中点后15–30ms）使用B0基线同帧锚点构造。其为读取完整基线轨迹的非因果oracle压力输入，绝不用于正常方法的初始化、预测或控制。
- `occlusion`：删除距baseline锚点x/y各≤13px的27×27方框内原事件。方框不等于物理Marker轮廓；可能同时删除重叠邻居部分，所有方框外事件逐字不变，真实邻近结构保留。干预结束原事件恢复，先前丢失的F仍不重接。
- `clone_plus8`：复制同帧baseline锚点±13px方框内原事件，x+8px，y/t/p及其他字段不变；原事件逐条保留，新事件只加副本。复制patch与原patch可重叠、改变同区域内容；这是合成相似结构混合压力，不是物理重录或真实换布局。输出干预副本与added/removed来源，输入原件不改。
- 有限隔离检查`outside_context_delete`：按baseline路径保护每帧当前/前一锚点±30px方框的并集，删除其外事件。B0的sigma0.8/truncate4核半径3px，正反向匹配读取范围至少来源锚点±(13+12+3)=28px；30px为保守保护，还覆盖本帧下一步的源上下文。逐步独立核对匹配实际访问的blur数组逐字相同、原始保护区事件逐字相同和输出相同。此为oracle实现隔离验证，不是布局泛化成绩。
- 所有尝试/拒绝/停止后帧保留；记录当前位置/提议、次佳峰、margin、FB、相对baseline锚点差、复制锚点距离。人工无真实身份标签，真实输入只能叫轨迹偏离/关联风险。合成复制的自动描述仅用预声明几何指标：接受位置距复制锚点≤3px且距baseline锚点≥5px、并至少更近3px，标`copy_anchor_attraction`，不当物理身份真值。
- 报告目标抹除是否及时拒绝、复制干扰是否歧义拒绝或发生接受偏离，明确证据不足时不能声称可靠拒绝。原始与压力帧图提供人工审阅；阈值不随结果调整。

不做logo检测宣称、跨真实布局泛化、PnP/三维旋转/训练/远程/硬件，不改原始输入或旧产物、不安装依赖。本轮只写此新目录。
