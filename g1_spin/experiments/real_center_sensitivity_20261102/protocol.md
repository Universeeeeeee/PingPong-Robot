# Frozen hypothesis sensitivity protocol — 2026-11-02

This is an offline experiment on recorded G1 events with **unverified center hypotheses**. All real-data outputs have `hypothesis_only=true`, `physics_validated=false`. There is no external synchronized center or spin truth. Nominal window midpoint is bookkeeping, not an instantaneous center measurement. Candidate disagreement and perturbations are not confidence intervals or physical error estimates.

Before examining spin results, use existing geometry observations: fixed48, fixed count threshold 0.6, durations 50 and 100 ms; all 31 nominal midpoints in each preselected segment. Fit ordinary least squares cx(t),cy(t) separately as first-order functions anchored at each segment midpoint. r=48 px throughout. This is a short-segment assumption, with no periodic model, marker-mean center, new detector, threshold tuning or spin-score selection. The observation midpoint range must cover all event/reference times; no extrapolation.

Segments: translation 0.30–0.60 s (geometry only), early 1.60–1.90, middle 6.20–6.50, late 11.20–11.50. Late remains an untrusted/failed geometry exit from prior work and is retained to expose failure, not rehabilitated by optimization. Prior reports show spatial-deletion and radius sensitivity, cy/r coupling, and uncertain silhouette identity; a smooth fitted line does not resolve those problems.

Spin windows, selected in advance, are [1.65,1.70), [1.80,1.85), [6.25,6.30), [6.40,6.45), [11.25,11.30), [11.40,11.45) s. Each is 50 ms, with no within-segment overlap. Every method uses its window arithmetic midpoint t_ref, identical raw event IDs and one common deterministic downsampling.

Nine variants per window (54 `estimate` calls total): A fixed at B(t_ref); B 50-ms candidate line; C 100-ms candidate line; B with constant cx +2/-2 px; B with cy +2/-2 px; B with velocity times 0.75/1.25 anchored at **each estimation window's B(t_ref)**. The latter is c_D(t)=c_B(t_ref)+alpha*v_B*(t-t_ref), isolating window-internal velocity. C can differ from B in both offset and slope. Constant cx/cy offsets cancel in aligned u'=u-c(t)+c(t_ref), but remain in sphere lift after subtracting c(t_ref); these variants isolate that sensitivity. These finite disturbances are diagnostics, not a measured center error model. Parent review accepted this protocol with the velocity anchor adjustment before optimization.

Before optimization, define the common event mask by raw ROI x in [475,638), y in [143,285), raw y<240, and distance <=0.8*48 px under **all nine** hypotheses at the event time. Record whole-window and ROI counts, each variant's pre-mask outside-r and outside-0.8r counts, common retention, and global event IDs. Use this mask once for every variant, followed once by linspace selection to at most 5000 events. No projection/clamping of outside points. The common mask intentionally excludes difficult events and limits conclusions to this selected interior subset.

Use the existing `spherical_cmax.estimate` unchanged: max_rpm=600, initial=None, its deterministic engineering grid/multistart and all existing quality gates. 600 rpm is a search setting inherited from the slow-spin scenario, not a supplied truth. Report returned validity/failures and rejected optimizer candidates distinctly. Compare omega vectors, directed axis angles, RPM and same-event contrast relative to A/B; these are method differences only. No best-performing center is selected from contrast.

Use only `translation.centers_at` mathematical interpolation; never fill synchronization_verified or ball_center metadata to bypass the verified-input contract. For each linear hypothesis, endpoint samples spanning the segment and max_gap_us=300000 provide coverage; independent closed-form evaluation verifies interpolation. Check identical event hashes and algebraic equivalence of aligned lift and direct (u-c(t))/r.

Verify original pixels/IDs/times recover. This is coordinate equivariance/code validation, not a DVS physical simulation or real-center validation; it uses zero extra optimization calls.
