# 第一次圆盘数据转速复核

目标：验证球心明显移动条件下的转速/减速结论，而非为缺失真值生成精确准确率。以10/29的222403（17.58s）作主分析；221756作独立录次的周期补充；221544强背景、相机移动仅沿用既有QC不强行估计。11/12点阵污染录制仅用于已完成的质量诊断，不作此次真值。

在本轮数值结果前固定：

1. 222403三个历史时段1.6–1.9/6.2–6.5/11.2–11.5s，使用20261102已保存50/100ms球心线性假设，禁止按旋转得分更新几何；半径48px，遮挡y>=240排除。
2. 每段0.3秒内3个中心（start+.05/.15/.25），20/50/100ms窗口，fixed50/linear50/linear100三方案；每窗三法同0.8r共同事件与5000上限。主搜索600RPM；每段中央50ms对三方案另用3500RPM做搜索上界消融。共81主结果+9扩展搜索。±2px半径在每段中央50ms、linear50上附加6次，记录几何系统敏感性而非置信区间。未用周期给轴或速度初值。
3. 新周期交叉检查：10ms原始ON/OFF占用图，Gaussian sigma1；不作球面提升、不用CMAX速度、允许2D平移配准；每个anchor在±0.10/±0.06/±0.02秒共6个源快门，向后搜索0.15–1.6秒、10ms网格。固定40px内部模板，源模板位置用既有球心近似（222403）或固定先验[552,215]（221756）；中心下移10px避下方遮挡；目标±25px水平/±8px竖直搜索。必须保留全部局部峰，包含倍周期竞争；相似度峰不自动视作完整一圈。
4. 周期anchor：222403 1.75/6.35/11.35；221756 2/14/24秒（沿用旧QC推荐区间）。每录次背景对照ROI移至左侧180px。1.6秒滞后内显著减速造成相似峰展宽；输出重复频率约对应源/目标中点，不伪称瞬时真值。
5. 图像预览核验同一标记复现、半周期差异和空间配准平移；局部匹配可退化，背景强相关或倍频无法消歧时保留不确定性。

结果必须区分：数值有效、图案重复证据、真实转速。球贴凸起反光Marker、下方遮挡和未经标定球心/半径仍存在，不能把此前电钻247RPM套到手动圆盘数据。Sony光流初始化实录此前未通过；本轮使用已实现的网格多初值s-CMAX核心，不宣称完整Sony在线复现。
