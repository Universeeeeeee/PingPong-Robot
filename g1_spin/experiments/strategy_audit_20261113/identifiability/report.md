# 平移与自转的局部可辨识性：几何限制已可量化

2026-11-13。只分析已冻结真实事件的空间分布和球面运动几何；没有把事件变成光流测量、没有拟合新的真实RPM、没有调用CMAX优化，也没有修改生产或旧实验。

## 结论

当前球内0.8r裁剪下，绕相机x/y轴的旋转所产生的图像速度，绝大部分可以由一个常量球心平移速度解释。这是原理上的近混淆，不只是优化器、窗口或平滑的选择问题。

即使乐观假设已获得完整、正确的二维光流，并且球心位置、半径和可见球面深度都正确，未知中心速度仍会使这两类旋转分量的局部证据大幅变弱。实际事件只有边缘法向运动、身份/反光/遮挡不确定，不能比这份乐观假设更轻松。

这不等于“永远不可能估计”：已知中心速度、跨区域不同z分布、长期可靠材料对应、额外视角/独立几何、可信轴先验都可补约束。但把同源轮廓拟合的短时速度当精确值，再把CMAX高分解释为自转正确，会低估这一混淆。

## 推导

相机x向右、y向下、z远离相机，单位球可见点s=(x,y,z)，z<0。像素半径为r，球心c。若表面材料点遵循刚体旋转：

```
u_dot/r = c_dot_x/r + z*omega_y - y*omega_z
v_dot/r = c_dot_y/r - z*omega_x + x*omega_z
```

定义待估参数 `[c_dot_x/r, c_dot_y/r, omega_x, omega_y, omega_z]`，均为s^-1。每点理想二维速度的Jacobian为：

```
[1  0   0   z  -y]
[0  1  -z   0   x]
```

球内0.8r意味着z落在[-1,-0.6]；z变化比其绝对值小。故omega_y列和水平平移列近共线，omega_x列和竖直平移列近共线。一个极端例子：所有点都落在同一个投影半径的圆环上，则z完全相同；两种横轴旋转可被平移精确抵消，联合5列仅rank3。

消去未知平移后，每点的z会变成`z-mean(z)`；omega_x/y列保留的平方范数比例恰为：

```
Var(z) / E[z²]
```

若有独立同方差完整流噪声，这可以对应最小二乘信息量的变化。但本数据没有这种流观测，本报告只称几何列能量，不能换算真实置信区间或CRLB。

## 真实输入分布结果

输入为圆盘复核的全部36个窗口（linear50球心假设）和后续电钻验证的32个预定旋转窗；其中22窗有保存的candidate输入，10个几何缺失窗原样保留。条件数按每窗sqrt(N)归一化，参数已统一为s^-1，避免混合像素与弧度单位。

|数据|权重|可用窗|平移/横轴旋转列相关绝对值范围|已知中心速度的旋转条件数中位|联合未知平移条件数中位|omega_x/y保留列能量范围|
|---|---|---:|---:|---:|---:|---:|
|圆盘|事件计数|36/36|0.9890–0.9941|1.81|16.46|1.18%–2.18%|
|圆盘|4px空间cell等权|36/36|0.9879–0.9924|1.66|14.75|1.51%–2.40%|
|电钻|事件计数|22/32|0.9896–0.9938|1.80|17.55|1.24%–2.07%|
|电钻|4px空间cell等权|22/32|0.9893–0.9919|1.48|14.65|1.61%–2.13%|

空间cell等权仍然高度混淆，说明它不只是同一点重复事件过多造成的假象。实际事件时刻、位置与冻结中心只是条件性几何采样，不能当成同时出现的独立已跟踪材料点；这些条件数更不能拿来判定某窗口实际光流通过。

在消去平移后，旋转最小奇异值相对已知平移时的比例中位约0.20–0.22；最弱方向对同等观测扰动更敏感。此比例与单列能量不是同一指标，不能混作“98%所有三维信息丢失”。

## 近混淆的像素量级

给每组假设球面点额外施加1rad/s绕x或y的角速度（大小约9.55RPM），同时求一个最能抵消该运动的常量球心速度。此求解只使用闭式投影、不使用估计器或真值转速。

- 圆盘所需补偿中心速度约37.6–42.8px/s，中位40.5px/s。
- 电钻约46.1–52.3px/s，中位48.7px/s。
- 用精确SciPy SO(3)而非仅线性速度展开，对这些假设点的窗口内像素预测比较，圆盘20/50/100ms的RMS残差中位分别约0.030/0.075/0.156px；电钻20ms约0.036px。

这解释了为什么圆盘原有约46px/s中心速度假设能让RPM变化约10，却很难单凭事件对齐图分辨哪组更对。它只是局部/假设点的模型预测分辨量级；没有完整材料对应与传感器噪声模型，不能将0.075px宣布为真实可辨阈值，也不能直接宣称两个实际非线性CMax解等价。

相同实验对omega_z留下更大的不可被平移抵消的像素差（圆盘中位约0.335px，电钻约0.172px），说明沿相机光轴的旋转在此几何中更易与平移分离；这不是说所有z旋转都可观测，轴上纹理等退化仍会发生。

## 内缩ROI的代价与取舍

规则均匀投影圆盘几何（非事件模拟）的联合条件数/横轴保留能量：

|最大归一化图像半径|联合条件数|保留能量|
|---:|---:|---:|
|0.2|341.5|0.0034%|
|0.4|79.8|0.0628%|
|0.6|31.7|0.4023%|
|0.8|14.7|1.9103%|
|0.95|8.1|6.5096%|

缩小ROI能避免轮廓误差/遮挡，却使z更接近常数，平移—横轴自转更难区分；直接扩大到0.95也不是答案，因为接近球边缘的lift、Marker凸起、透视和轮廓误差更敏感。这是必须显式处理的观测设计取舍，不能只选对比度高的ROI。

## 建议的路线选择

1. **固定轴电钻**：用独立已知轴方向或刚性装置约束做条件性一维转速估计，先验证速度大小；不要把轴先验用进去后再宣称恢复了未知三维轴。正反转应使用有向轴，不能取绝对点积隐藏翻转。
2. **圆盘明显平移**：保留图案重复作为条件性转速交叉证据。对短窗CMAX同时报告中心速度/半径假设包络，除非加入独立球心速度约束，否则不推荐继续自由联合优化5维平移＋旋转来追求更高分；局部混淆会制造漂亮但不唯一的解。
3. **要恢复完整3D旋转**：优先补“独立中心运动/深度尺度”和“可确认材料对应或正常边缘流”。多区域有不同z、跨时间可追踪标记、受控固定中心、第二视角/同步中心参考，比继续增加多初值方向或仅延长窗口更能增加约束。
4. **保持证伪评价**：任何新方案必须用不参与拟合的空间区域/未来时间验证预测，和纯平移、时间置乱/事件极性结构对照；绝不能把同源CMax增益当独立验证。
