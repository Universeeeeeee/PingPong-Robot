# 正交球面旋转与平移的局部可辨识性

固定分析，不拟合真实角速度、不调用CMax优化。数据为已保存圆盘复核36窗的linear50几何和候选验证电钻32个预定旋转窗中存在的candidate输入；不选择最优结果。每份记录只描述事件占据的几何位置。另用规则网格产生可观测几何上界，不把其当DVS仿真。

假设一个理想传感器能给每个被观测点完整二维速度，且球心/半径/可见半球位置已知。单位球s=(x,y,z)，z<0；像素半径r，u=c+r[x,y]。小运动为
u_dot/r = c_dot_x/r + z*omega_y - y*omega_z
v_dot/r = c_dot_y/r - z*omega_x + x*omega_z。
列顺序[c_dot_x/r,c_dot_y/r,omega_x,omega_y,omega_z]；同量纲s^-1。每点2×5 Jacobian=[[1,0,0,z,-y],[0,1,-z,0,x]]。

每窗分别按事件权重、4px空间cell等权分析（后者每cell一个实际最接近median点），归一化矩阵尺度以免事件数伪造信息。报告已知中心速度的旋转条件数、未知平移联合条件数、平移子空间消去后的旋转奇异值、tx/wy与ty/wx列cosine以及每个omega列保留能量比。条件数不是估计精度或置信区间。

独立交叉检查：SciPy Rotation中央差分重建小运动Jacobian；显式Q投影与逐坐标减均值重建平移消除结果；解析均值/方差计算列相关和omega_x/y保留能量。输入、几何代码、报告来源记录SHA256；不改生产和旧产物。

额外展示与沿x/y平移最容易混淆的1rad/s绕轴扰动，拟合一个恒定平移速度后，在实际窗时间内比较线性/精确SO(3)预测像素差。这只是同一组假设三维点上的物理预测分辨量级，不是现实运动真值或真实事件匹配误差。未知边缘法向及材质身份会使真实约束比本乐观完整流假设更弱。
