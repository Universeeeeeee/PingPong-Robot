# Sony方案：观测条件与可辨识性审查

2026-11-13。独立只读核对项目既有证据，并重新打开原论文v2及官方近似伪代码。未控制设备、未修改生产实现。

## 结论

当前最应迁移的是Sony的“先建立旋转占主导的可观测数据，再做旋转估计”的系统设计。把原始事件事后搬到估计球心，只改变坐标，不会撤销平移、遮挡、反光和主动光源在采集时已触发的事件。因此当前主要瓶颈是观测模型与参数可辨识性，不是再搜索更密的omega网格。该判断不等于现有录像完全没有旋转信息：圆盘减速的重复图案证据可以保留，但精确3D自旋尚未被识别。

## 原文直接支持的差异

[原论文v2](https://arxiv.org/html/2606.26780v2)的§3.1–3.4说明GCS先以主动跟踪抵消成像平移、保持细节与清晰度；离线光流初始化后自由细化自旋，在线则以CNN轴方向为先验只细化幅值。§4.2 spinner有编码器/轴标定；§4.3说明静止EVS的速度大小可能偶合接近而轴错误。论文spin测试主要是1000RPM以上，我们70–247RPM是不同观测区间。官方[近似代码](https://sonyresearch.github.io/ace_public/pseudo_code/)使用OFF最近时间面，并在50rad/s以下跳过在线幅值细化；这些不能被当作完整生产实现。

核查定位：论文§3.1.2（主动光学、ROI、标定）、§3.2.2（共享硬件触发）、§3.3.1/2（离线初始化与球面IWE）、§3.4.2（在线固定轴搜幅值）、§4.2（spinner真值）、§4.3（静止相机的混淆）；官方代码EventCamera.polarities/events_to_time_surface和spin_refinement_thread。

上述公开来源仍未明确离线normal-flow梯度到切向“normal velocity”的全部度量细节；不得根据我们A_literal失败宣称Sony算法或实现错误。在线OFF/latest表示也不能倒推成离线全文唯一表示。

## 数学上为何中心与横向自旋耦合

正交球面近似中，令单位可见球面点s=(x,y,z<0)、半径r，球心速度为(cdot_u,cdot_v)，则：

```
udot/r = cdot_u/r + omega_y*z - omega_z*y
vdot/r = cdot_v/r + omega_z*x - omega_x*z
```

球中心附近z≈−1，omega_y几乎等价于恒定水平平移，omega_x几乎等价于恒定垂直平移；omega_z的旋转形变相对更容易和常量平移区分。跨球面深度变化才提供区分x/y自旋与平移的证据。但越靠轮廓，提升又对中心/半径更敏感，所以扩大ROI并非没有代价。

`observability.py`用保存的原始窗口几何，按4px空间格去除重复事件数量权重，构建假定“完整二维速度可测”的五参数设计矩阵。实际事件只提供法向约束，且反光/投影可能不遵循材料速度，因此这是乐观几何检查，不是实测flow或噪声Fisher信息。

|输入支撑|平移可吸收横向自旋设计列能量|五参数条件数|
|---|---:|---:|
|圆盘早段|98.40%|16.58|
|圆盘中段|98.30%|15.81|
|圆盘晚段|98.40%|16.92|
|圆盘明显平移段|97.86%|14.38|
|固定电钻代表窗|98.18%|15.28|

该“能量”是线性设计列与常数列的投影比例，不是98%的真实旋转被误判，也不是98%不可识别概率。条件数也不是自动拒绝阈值。它解释了为什么约1px中心变化误差能转移到omega的横向分量，且IWE仍可能保持很高。

中心rho≤0.1的解析支撑，其五参数条件数约1292；rho≤0.8时约14.9。`verification.json`使用独立SciPy SO(3)正负时间有限差分核对公式，最大绝对误差4.63e−11；中心处旋转和平移精确等价也通过。所有结果在`observability.json`。

## 现有证据的正确解读

- `drill_phase3_20261106/report.md`：G网格CMax可产生方向/反转一致候选；A/S因局部plane不足未形成实录估计，不是测到零。
- `drill_phase4_20261106/semantics.md`：g是时间对像素的协向量。完整运动约束是r(s×[gx,gy,0])·omega=1−gᵀcdot。`normal_flow−cdot`不是完整去平移；A_literal和标量S不等价，不能混名。
- `drill_phase4_20261106/report.md`：干净合成上CMax提高IWE后反而略离开更准确的S初值。这是目标函数与物理误差不等价的实际例子。
- `drill_phase5_20261106/report.md`：大部分旧全事件邻域不可能由一个单值t(x,y,p)满足原plane门限；换latest/像素法向拟合仍没有通过留出运动证据。继续放宽邻域/门限的收益不足。
- `disk_recheck_20261113/report.md`：search bound600→3500几乎不改RPM；radius46→50却显著改RPM。说明现有主要不确定性在几何尺度/观测而非被搜索范围截断。
- `marker_model_audit_20261101/report.md`：第一次录像是凸起反光Marker球；其真实观测点未必共球面，反光事件也未必跟随标记几何中心。
- `dual_capture/analysis_20261112/report.md`：最新投射点阵属于外部照明图案。它是极有用的“非材料纹理”负例，而非可靠自旋正例。

## 三个有限、可证伪的实验

1. **联合平移/自旋可辨识性剖面，而非再调球心。**在固定几何和训练事件上扫描有限中心速度假设，对每种假设重求omega；只用共同未参与拟合的时空事件评估预测。若宽范围cdot/omega组合具有近似相同留出误差，结论是只能给候选集合，不能给单一精确轴。先用已知二维完整流合成校准该剖面，再用真实法向/事件输入。仅训练IWE同分不够。
2. **材料纹理假设的压力测试。**固定旧干净圆盘/电钻与新点阵片段，比较原始时间、分块时间置乱及前后分离的预测效果；控制保留像素/极性/事件数。真实模型应能预测未来不同空间区域，置乱后应失去优势；若新点阵或置乱仍给出稳定高置信自旋，需先修观测/评分准则。时间整体反向只验证算法符号等变性，不能单独作为真实旋转证明。
3. **降维到可检验的刚体问题。**在少量清晰标记片段人工固定跨时对应（不从CMAX轴反推身份），拟合相邻较长区间的2D刚体投影/中心运动，做留一标记与未来时段预测，并与translation-only竞争。若对应不能稳定预测，则保留周期幅值证据，停止包装三维轴；若通过，再比较球面固定半径与少量凸起/布局参数，而不是完全自由joint优化。不得把一半数据挑出的标签再次当独立验收。

## 路线建议

当下输出分为两层：可信度较高的是减速趋势、图案周期及受条件限制的幅值量级；完整3D角速度只能是可拒绝的候选。优先把“哪些模型能解释未见观测”做成判据；第二次电钻可作为方向/相对反转和约247RPM的弱参考；第一次圆盘用于检验平移混淆；第三次点阵用于负例。暂不训练CNN、扩大网格或继续Hough微调，因为缺少可信标签时这些步骤只会更快复现现有偏差。

后续若需Sony级精度，应先使真实材料纹理清晰、中心在传感器上足够稳定、光照不引入投射图案，并取得可标定的轴与幅值参考。无需立即复制昂贵的整套GCS，但必须明确替代了哪些观测条件，不能声称软件重心对齐等价于主动视觉。
