# 从Sony系统设计重新判断旋转估计路线

2026-11-13。本轮并行进行Sony原文审查、平移/旋转可辨识性分析、历史数据证据审计；随后完成固定前段拟合/后段预测与真实中心速度剖面实验。只复用已有本地原始派生数据，Linux新录制的质量诊断作为负面证据，不重新控制硬件。没有修改生产估计器或旧实验结果。

## 核心结论

**s-CMAX值得保留；应停止把“完整三维旋转精度”主要当成优化器参数问题。当前数据含可预测的旋转相容运动信息，但中心运动、球面尺度及材料观测不确定，使精确RPM/未知三维轴不能唯一确定。**

这不是“现有数据完全不能用”，也不是“模型已准确复现Sony”。旧圆盘适合检验平移混淆与减速趋势；固定电钻适合方向/反转与条件性速度；11/12点阵污染录制适合录制链路和非材料纹理干扰诊断。不同数据的标签、标定不能跨录次拼成真值。

最有决策价值的新结果：人为改变中心水平速度假设，真实CMAX给出相差约30–36RPM的候选族，但对未见事件的像素预测距离只变化约0.015–0.022px。几何理论与实际优化/留出预测一致表明，单靠当前短窗事件评分不足以裁决哪个RPM更准确。

## Sony系统真正依赖的条件

依据[Sony论文v2](https://arxiv.org/html/2606.26780v2)及[官方近似伪代码](https://sonyresearch.github.io/ace_public/pseudo_code/)，详见sony/audit.md：

- 主动视线系统在事件生成之前稳定球像，并用窄视场/调焦等条件保持表面细节。事后减球心只改变坐标，不能撤销平移、遮挡和反光已经影响的事件生成。
- 公开在线路线使用网络给出的轴方向，再细化旋转幅值；我们的自由三维网格多起点CMAX属于离线工程替代，不能直接称作相同在线实现。
- 论文乒乓球spinner主验证区间1000–9000RPM，而现有圆盘约70–220、电钻约247RPM处于不同观测区间。近似在线代码50rad/s以下跳过幅值细化，只是该示例的策略门槛，不是证明低速CMAX物理上不可用。
- 光流初始化从来需要可信边缘时空结构。旧实录局部时间面反复失败已有结构诊断，继续放宽门限不能代替真实运动证据；也不能据此宣称Sony未公开实现错误。

因此可以借鉴Sony的观测设计、分工与验证方式，不应简单复制几个参数或默认10ms适合所有转速。

## 新实验A：前段拟合是否预测后段

固定9个实录窗口（圆盘4、电钻4种轴向、纯平移1）以及2个理想几何正例。仅前60%时间拟合omega，后40%不进入优化；训练末短模板前向预测后段4个子片。对照zero（给定中心平移仍保留）、反号omega、3种仅训练时间对应置乱。输入选择和几何来自历史全窗产物，故这是**给定几何的条件性验证**，不是因果端到端盲测。

|圆盘早段|是|1.000 / 2.004|50.1%|否|

7个native有效真实旋转候选的像素预测均优于全部对照。27个实录时间置乱输入均被原门限以no_rotation_evidence拒绝。两个理想正例通过仅验证该检查能区分某些正例，不等于实拍精度。

预声明要求像素预测与train/holdout球面IWE余弦都胜出，因此正式双指标通过为**4/9实录**。前三个圆盘窗口虽然像素预测改善，但IWE余弦不胜出，未事后改规则把它们算成正式通过。这表明表示/评分不同会产生冲突；不能仅据此宣布IWE指标必然错误。下一版本可把原像素预测作为单独主指标，但须另行校准，而非追认本轮通过。

puretranslation诊断候选严格数值上也可略胜zero和三个null，但只改善0.46%、原门限拒绝。任意微小分数提高不构成物理运动证据，不能据此放宽门限。

评分是按极性、双向最近邻、3px截断的工程代理，不提供材料点身份。disk留出片宽5ms、drill为1ms，事件密度/响应尾迹/照明仍可能影响结果；样本和置乱数量少，没有统计显著性结论。正确表述是“现有事件含能预测未来观测、与旋转模型相容的运动结构”，不是“已测准真实角速度”。

## 新实验B：理论上哪些参数容易混淆

单位可见球面点s=(x,y,z<0)，像素半径r，观测速度满足：

```
u_dot/r = center_vx/r + z*omega_y - y*omega_z
v_dot/r = center_vy/r - z*omega_x + x*omega_z
```

球内0.8r的z变化较小，中心平移与omega_x/y设计列高度相关。两个独立实现得到一致量级：在圆盘36窗和电钻22个有输入窗中，列相关约0.989–0.994；消去未知平移后横轴旋转列只剩约1%–2%的平方范数。4px空间格等权仍如此，不是重复事件计数造成。

**这个百分比不是98%的实际旋转被误判、也不是98%的真实信息丢失。**它来自假定完整二维光流可测的乐观线性几何模型，不是实际事件测量、误差概率或CRLB。矩阵通常仍满秩；是病态/近混淆，不是断言永远不可能识别。

约9.55RPM横轴变化可被圆盘约40px/s中心速度变化大幅抵消。在给定假设点的50ms模型中，剩余像素预测差中位约0.075px。这个量级解释了中心输入为何敏感，但不能当真实传感器分辨阈值。见identifiability/report.md。

## 新实验C：真实数据中的候选族

只在两个固定窗口增加中心速度vx偏差−80/−40/0/+40/+80px/s，保持训练末中心位置、半径、原始像素、事件ID/顺序、训练/留出划分不变。每种假设只用训练集重求omega，不按留出得分选速度。

|case|五假设RPM范围|后段像素距离范围|零偏差RPM / 距离|
|---|---:|---:|---:|
|圆盘明显平移|205.38–240.93|1.2335–1.2549px|227.18 / 1.2519px|
|固定轴电钻|248.16–280.02|0.8149–0.8292px|262.44 / 0.8246px|

±80px/s是人为敏感性假设，未测得实际中心误差；上表不是RPM置信区间。它说明在当前评分分辨率下，相当不同的条件性角速度仍可解释未见事件。五假设的预测目标始终是同一原始像素，未随着中心假设改变“真值目标”。全部5000事件保留，不靠变更掩膜制造得分接近。中心固定在训练末，最大训练中心扰动圆盘约2.4px、电钻约0.48px。

剖面结果不意味着所有中心假设物理上都成立，而是必须有额外中心/轴/材料观测约束，才能选择其中一个。先前单纯提高对比度、重复拟合或扩搜索不能完成这种选择。

## 周期证据也应降到正确层级

独立证据审计复算222403四组图案最高峰所需的自由配准平移，与旧外弧中心位移的差异中位约4.68/8.13/1.49/3.88px。可能是相位差被平移吸收，也可能旧中心或反光模型错误，不能唯一归因。高相似度不等于完整一圈的独立认证。电钻事件周期约0.48秒主峰与0.24秒次峰的竞争也仍需保留；不能因为另拍手机约247RPM就挑最近峰作为真值。

这不推翻圆盘减速量级：CMAX、图案复现和未来预测提供相容的条件证据，但三者共享数据，不能相乘成绝对精度认证。

## 电钻固定轴一维验证

已在第二次电钻数据上完成已知轴一维 CMAX；结果见[axis1d报告](axis1d/report.md)。run1竖直粗轴中位约258.8RPM，run2相机法向轴约254.4RPM，run3图像平面斜轴约283.0RPM，run4反向粗轴中位约247.1RPM；相反图像轴符号保持物理正反转关系。它验证的是“已知轴条件下标量角速度可估计”，不是未知三维轴精度。

## 路线裁决

|场景|现在适合输出什么|下一次要增加的约束|
|---|---|---|
|圆盘球心明显移动|速度量级/减速趋势、随几何变化的候选范围、未来预测诊断|独立中心速度或可稳定对应的多个材料标记；不做无约束5维联合优化来追高分|
|电钻固定轴|在独立已知轴下的一维有向转速，可用同档位视频作弱参考|轴需装置/标定给定；不能由本算法输出轴后再当先验验证自己|
|未知完整3D自旋|允许拒绝的三维候选，附预测和几何敏感性|材料纹理与观测质量、可辨几何、独立轴/速度参考|
|11/12投射点阵数据|非材料照明干扰、录制/时间戳/粗同步诊断|关闭主动点阵并改善均匀照明；当前不输出可信真实自旋|

可保留：球面几何、原CMAX作为条件性拟合器、明确的无效输出、几何回退、同输入对照和预测诊断。

不再优先投入：扩大网格、反复微调Hough/球心平滑、仅靠长窗口、继续放宽局部plane阈值、在没有可靠标签时训练轴CNN。单独增加自由度甚至可能增强混淆。

**工程上更合理的下一阶段是“先约束容易验证的低维问题，再扩展未知三维轴”：固定轴速度→独立中心下旋转→材料对应/多视角下未知轴。**不必立即复制Sony整套主动机构，但必须明确替代它提供的哪些观测条件。当前旧数据已经足够支持这次路线裁决，不需要继续在相同小片段上调参数才算得出结论。
