# 光流初始化障碍与搜索策略复核

2026年11月14日。本轮核对现有调用链，并在本地旧录像和独立生成的球面边缘事件上重新实验。粗光流初始化已经在旧实录上贯通到单次三维CMAX。旧前端对局部时间平面的严格要求，曾使所有候选在搜索前退出。新录制脚本沿用直接网格调用，尚未尝试光流。Linux关机，11月13日新RAW窗口本轮未运行光流实验。

在旧10ms窗口上，粗光流加单次优化、直接零初值单次优化与网格法接受相同53个窗口。随窗口延长，初值开始影响局部最优。100/150ms四个代表片段中，粗光流均找到网格附近的解，零初值在三个片段失败。250ms时粗光流仍有两个片段偏离网格结果。网格结果用于同一优化目标的数值比较，物理精度仍取决于事件及几何模型。

## 当前为什么只跑网格

生产分析入口 `src/g1_spin/cli.py:149` 直接调用球面CMAX。光流仅在合成benchmark中作为独立baseline出现。11月13日的spin、spin_short和spin_10ms同样直接调用CMAX，没有光流提取或初值调用。

`src/g1_spin/spherical_cmax.py` 的 `initial` 参数只给完整方向网格追加候选。真正沿光流初轴扫描幅值、再做一次三维Nelder–Mead的路径已存在于 `experiments/drill_phase3_20261106/methods.py:axis_search`。本轮直接复用这条路径，记录单次NM，未经过网格候选或网格回退。

历史阶段3的A/S在108窗中都未进入一次实际搜索，76窗缺少足够光流约束，20窗缺几何，12窗事件不足。当前调用链的选择沿用了这一历史结果。新录像的光流能否工作仍需其原始窗口进行检验。

## 光流前端实际卡在哪里

旧前端在同极性、4px半径、正负2ms邻域内拟合时间平面 `t=a*u+b*v+c`，要求至少10事件并有二维空间支撑。它的时间残差门限为 `RMS ≤ max(20μs, 0.15*std(t))`。在非20μs下限分支，等价于解释至少97.75%的时间方差。

真实邻域中，同一像素、同一极性经常有多次不同时间的事件。单值时间平面无法同时解释这些记录。旧阶段5已证明多数邻域的像素组内时间方差下界超过原门限。本轮在8个存档窗口重新检查，原4px/正负2ms/0.15设置仍为零接受平面。将时间邻域缩为正负0.5或1ms，或在同一离线邻域取每像素最新事件，保留原0.15门限时也全部为零。

本轮96组前端敏感性检查中，放宽残差比到0.5或0.8可以得到足够约束。粗速度可达约360至730RPM，表明放行本身不能保证局部运动准确。将这些粗方向继续送入单次CMAX，32组代表配置中16组有数量及满秩支撑，14组旋转窗口通过最终算法质量门，两个平移窗口被旋转证据门拒绝。

原严格前端在新生成的6个理想材料边缘场景中全部可用，接受120至296个局部平面，最小二乘轴误差约0.02至0.13度。这表明原方程和实现能够处理符合模型的事件。实录中的多时间层、多边缘、响应尾迹、噪声及局部曲率等成分，尚未被现有前端可靠区分。具体成因之间仍有歧义。

前端诊断见 [gate_diagnostics.json](gate_diagnostics.json)，严格合成复核见 [strict_flow_report.md](synthetic_basin/strict_flow_report.md)。

## 粗初值能够运行 但局部光流仍不稳定

另一条固定候选使用已有空间法向回归M_spatial。先在12px网格中按事件数量取6个区域，再分成5个2ms段，分别拟合ON和OFF的单位图像法向n及法向速度vn。以球面几何构造标量约束，最小二乘得到初角速度。

对单位球面点s、半径r、球心图像速度c_dot，正确约束为

`r*(s cross [nx,ny,0]) dot omega = vn - n dot c_dot`。

若使用时间梯度g，则右端为 `1 - g dot c_dot`。本轮主要对照沿用旧B1固定球心假设，另行诊断已有球心割线速度。直接将二维法向速度当完整二维速度再切向提升，会改变aperture约束的度量。旧A_literal解释存在该差异，生产标量S公式保持原图像法向约束。Sony公开正文不足以确认其内部梯度到切向normal-flow的全部细式。

新的粗候选要求至少6条观测、3个区域、rank3和条件数不超过100，局部需要12个独立像素。它使用已有M_spatial，改变了邻域组织和粗候选资格，没有把此前0.5px最终局部运动验收线作为运行CMAX的前提。该整条变化与单纯放宽时间平面门限的实验分别保留。

四个代表旋转窗的粗初轴对旧G差约16至56度，全局约束RMS约421至1226px/s。移除一个区域后，反转窗粗轴最多变化70度。斜轴窗单独用ON观测时出现约2459RPM的粗候选。已有球心割线补偿通常仅改变几度，不能统一解释这些偏差。当前局部观测尚不足以直接作为可靠轴测量。

独立重算用二维坐标对时间回归后的空间残差SVD恢复M_spatial，法向与保存结果最大差约6e-15，法向速度最大差约3.64e-12px/s。没有发现钻杆轴或RGB速度进入候选拟合。

具体结果见 [粗候选报告](coarse_seed/report.md) 与 [约束敏感性](constraint_sensitivity.json)。

## 108个旧窗口的完整链比较

| 路线 | 算法接受窗口 | 与网格RPM差中位数 | 与网格有向轴差中位数 |
|---|---:|---:|---:|
| 原网格及多起点CMAX | 53/108 | 基准 | 基准 |
| 粗光流及单次CMAX | 53/108 | 0.072RPM | 0.049度 |
| 零角速度及单次CMAX | 53/108 | 0.107RPM | 0.048度 |

三条路线接受相同的53窗。粗光流路线70窗获得初值，最终53接受、17因缺旋转证据拒绝，另外20缺几何、12事件不足、6粗初值支撑不足。20个事件充分的纯平移窗最终均未输出旋转。12个静止窗因事件不足而无输出。

四个代表旋转窗分别尝试6个坐标轴和4个固定随机方向，40次单次CMAX均得到网格附近的结果，其中23次沿轴幅值扫描选中了零向量。run1时间置乱得到偏离G约65.5度的初轴，送入干净事件CMAX仍恢复网格附近结果。整条CMAX输入也置乱后则拒绝旋转。因此旧低速10ms样本中的一致结果包含明显的优化器纠正贡献。

粗光流与零初值单次路线使用共同质量门。G另有多起点竞争检查。相同接受集合是本批实测结果，不等于两种质量机制等价。粗候选扩展和零初值实验使用phase3存档selected事件，11个窗口曾截断至5000事件，继承旧几何及ROI。它们属于既有数据的探索性扩展。

完整记录见 [108窗粗初始化扩展](coarse_seed/extension/report.md)、[零初值结果](zero_seed_results.json) 与 [固定方向控制](seed_controls.json)。

## 较长窗口中 初值开始影响求解

四个旧代表时刻重新从本地官方解码事件中提取窗口。三条路线共用固定B1球心和半径、0.8r区域、最多4000个相同事件、1200RPM上限和相同简单形。中央10ms估出的粗轴用于沿轴扫描后自由三维优化。窗口内球心保持固定是本轮对照假设，长窗物理精度需另外验证。

| 窗口 | 零初值对网格结果 | 粗光流对网格结果 |
|---|---|---|
| 10ms | 四窗近似同解 | 四窗近似同解 |
| 50ms | 四窗近似同解 | 四窗近似同解 |
| 100ms | 三窗陷入较低分局部解 | 四窗近似同解 |
| 150ms | 三窗陷入较低分局部解 | 四窗近似同解 |
| 250ms | 四窗均较低分 | 两窗近解，另两窗仍偏离 |

100ms首次观察到零初值失败的三个样本，网格候选的角位移约164至167度。它只是本次离散窗口试验的结果，不是通用阈值。

250ms的run1中，粗光流路线得到249.27RPM，网格得到250.09RPM，有向轴相差27.01度。run3粗光流路线为361.11RPM，网格为250.44RPM，轴差47.46度。粗初值虽能帮助部分长窗，仍可能进入错误的局部极值。

60个候选中58个通过共同质量门。很多低分解仍然收敛、未触搜索上界，且相对零运动有超过8%的对比度增益。现有单次优化质量门不能判断另有更高分候选。网格取得的较高分也只代表优化目标上的比较。

全部轴、角速度、目标分数和调用数见 [20组窗口对照](window_extension/report_all.md)。

## 合成反例说明初始化的价值与边界

复用阶段4的六条材料球面大圆弧，独立生成240、1200、3000RPM与10、50ms组合。每个场景重新解析求整数像素穿越时刻，包含可见半球变化，独立校验旋转残差和极性。该理想生成器未模拟实际DVS阈值、尾迹、反光或照明。

1200RPM乘50ms覆盖一整圈，零初值、粗光流、真值初值及网格均得到约1202.7RPM、0.36度轴误差。3000RPM乘50ms覆盖2.5圈，零初值停在6.33RPM并被拒绝，粗光流与网格均恢复约3000.05RPM、0.277度轴误差。

一整圈及可见性变化本身不足以解释真实长窗的数十度轴偏差。真实几何误差、局部事件生成与CMAX目标的相互作用仍需排查。六个合成场景中，从精确真值开始优化也会获得更高IWE并偏离真值，幅度约0.28至0.78度。当前对比度离散化本身存在小幅目标偏差。

生成、真值隔离与留出检查见 [合成研究报告](synthetic_basin/report.md)。

## 当前判断

光流初始化的可执行通路已在旧实录上建立。先前实验主要验证局部光流能否达到严格测量质量，在这一层停止后没有继续检验粗候选对最终优化的作用。本轮补齐了这一实验。

更具体的障碍是可信局部法向运动提取、粗轴的空间稳定性，以及长窗局部极值的识别。对这批低速10ms样本，直接零初值已能复现网格结果。对较大角位移，粗光流可以减少单次优化落入局部极值的风险，但尚不能统一替代多候选搜索。

当前结果来自旧Nov5录像、既有球体几何和理想合成模型。11月13日新录像的光流实验等待采集机可访问。生产入口仍保留原实现，本轮新增内容位于本实验目录。

现有光流及阶段3数学测试通过2项。数值汇总、输入SHA256与接受集合核验见 [summary.json](summary.json) 和 [verification.json](verification.json)。
