# 电钻球心与窗口离线对照

范围：不修改生产估计器；先固定本协议，再运行一次比较。

- 手机60fps参考采用 originals/results.json 的贴片A过线转速及保守读数范围。手机与事件录像尚未确认对应关系，未确认前不计算逐窗真值误差。
- 固定窗口结束时刻：run1 1.435/1.505/3.605/4.375s；run4 0.905/1.705/2.505/3.305s；run5平移4.105/5.105/6.105/6.505s；run5静止0.535/1.535s。前两窗 development，后两窗 evaluation；静止各一窗。来自既有诊断片段，非独立盲测。
- 每个结束时刻分别取前10/20/40ms。比较fixed（窗口中点中心）、linear（逐事件插值）、median3（原几何观测连续三点逐坐标中值后插值）。只在相邻几何支点间距均不超过30ms时平滑，缺口不填。
- 沿用已审阅的轮廓几何观测和60px半径。固定静止位置先验714/355。不利用CMAX或RPM选择几何。
- 同窗三种中心使用共同0.8r内区事件，最多5000个等间距事件ID，保持整数微秒时间差。不同长度窗口事件不同，报告事件数与保留比例。
- 为保证对照完整，使用离线已有几何观测（可能包含窗口结束后的支点）。记录所用几何最晚快门结束时间相对窗口末的lookahead；不宣称因果在线性能。
- CMAX固定3500RPM上界，沿用生产多轴搜索、Gaussian和质量门限。失败保留null，不以约250RPM限制搜索或选峰。
- 报告每组有效率、RPM分布、耗时、平移/静止非零输出；转速参考只在关系确认后按对应口径使用。三维轴没有精确真值，不报告真实轴误差。
- 不依据评价片段反复修改参数；无明确证据不替换生产默认。
